# Provider logos

Used by the main window and settings page. The PNGs are embedded into the
binary via `include_bytes!`, so no runtime icon-theme dependency is needed.

- `bing.png` — Bing official favicon mark (transparent): https://www.bing.com/favicon.ico
- `volcengine.png` — Volcengine official favicon mark (transparent): https://portal.volccdn.com/obj/volcfe/misc/favicon.png
- `alibaba.png` — Alibaba Cloud mark from Simple Icons (CC0), colored orange, transparent: https://github.com/simple-icons/simple-icons/blob/develop/icons/alibabacloud.svg

To swap in official brand assets, keep a transparent square PNG at least 96x96.
