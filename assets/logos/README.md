# Provider logos

Used by the main window and settings page. The PNGs are embedded into the
binary via `include_bytes!`, so no runtime icon-theme dependency is needed.

- `bing.png` — 简化字标：Microsoft 蓝底 + 白色 b
- `volcengine.png` — 蓝底 + 白色“火”
- `alibaba.png` — Alibaba Cloud mark (Simple Icons, CC0) + 橙色底

替换为官方品牌资源时保持 1:1 方形、透明圆角、至少 96x96 即可。
