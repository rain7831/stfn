# 配置窗口与密钥存储

> 状态：待审核 · 目标版本：v0.1
> 关联：`README.md`、`ui.md`、`config.md`、`architecture.md`

## 1. 入口

- 主窗口顶栏齿轮按钮。
- `Ctrl+,`。
- 命令行 `stfn settings`：GUI 未运行时先启动 GUI，再打开设置；已打开则聚焦。

设置窗口是独立顶层窗口，非模态；同一时间只允许一个实例。

## 3. 字段与行为

| 字段 | 控件 | 默认 | 规则 |
| --- | --- | --- | --- |
| `general.auto_translate` | `AdwSwitchRow` | `true` | 关闭后主窗口显示“翻译”按钮 |
| `general.debounce_ms` | 滑块 + 数值 | `300` | 200–2000，步进 50；自动翻译关闭时禁用 |
| `providers.bing.enabled` | `AdwSwitchRow` | `true` | 无密钥 |
| `providers.volcengine.enabled` | `AdwSwitchRow` | `false` | 开启时要求 AK/SK 齐全 |
| `providers.volcengine.region` | `AdwEntryRow` | `cn-north-1` | 非空；常用区域下拉可选 |
| `providers.tencent.enabled` | `AdwSwitchRow` | `false` | 开启时要求 SecretId/Key 齐全 |
| `providers.tencent.region` | `AdwEntryRow` | `ap-guangzhou` | 非空 |
| 密钥 | `AdwPasswordEntryRow` | 空 | 默认掩码，可点“显示”临时明文 |

密钥不显示完整值：未编辑时显示占位圆点；从 keyring / 文件读出的值也不回填明文到输入框，只在保存时按“是否修改”处理。

## 4. 保存流程

1. 校验字段（见第 6 节）。
2. 对修改过的密钥写入 Secret Service；环境变量来源的字段跳过。
3. 用 `toml_edit` 读改写 `config.toml`，保留注释与格式。
4. 原子写：同目录临时文件 → `fsync` → `rename`。
5. 更新内存中的 `ConfigStore`。
6. 主窗口按需更新：延迟立即生效；provider 集合变化时重建结果行。
7. 显示 `AdwToast` “已保存”。

保存期间禁用“保存”按钮，避免并发写。

## 5. 密钥存储

### 5.1 优先级

```
环境变量 > Secret Service > credentials.toml (0600) > 空
```

- 环境变量存在时，该字段在 UI 中只读，并显示“由环境变量 `STFN_...` 提供”。
- 环境变量永远不会被写回 keyring 或文件。

### 5.2 Secret Service（首选）

- 通过 `oo7`（zbus，纯 Rust，无 libsecret C 依赖）访问。
- 使用默认 collection（通常是 `login`）。
- Item 属性：
  - `application = "stfn"`
  - `provider = "volcengine" | "tencent"`
  - `field = "access_key" | "secret_key" | "secret_id"`
- Label：`STFN · Volcengine Access Key` 等。
- 保存时按属性查找并替换，不产生重复条目。
- 读取失败 / 无 Secret Service：进入 5.3。

### 5.3 文件回退

- 路径：`$XDG_CONFIG_HOME/stfn/credentials.toml`（默认 `~/.config/stfn/credentials.toml`）。
- 目录权限 `0700`，文件权限 `0600`。
- 只在用户明确确认后使用；不静默降级。
- 写入方式与 `config.toml` 相同：`toml_edit` + 临时文件 + `rename`。
- 不保留凭据文件的 `.bak`，避免多份明文副本。

```toml
# credentials.toml
[providers.volcengine]
access_key = "..."
secret_key = "..."

[providers.tencent]
secret_id = "..."
secret_key = "..."
```

### 5.4 保密措施

- UI 默认掩码；显示按钮只在按住 / 点击后临时显示，失焦立即恢复。
- 不把密钥写入日志、panic 信息、错误消息、桌面通知、剪贴板。
- 内存中使用 `secrecy::SecretString` / `zeroize`，用后清零。
- 日志只记录 provider、状态、耗时；请求头与正文不落日志。
- 设置窗口截屏 / 录屏不额外处理，但密钥默认不可见。

### 5.5 密钥环不可用

弹出对话框：

- “无法访问系统密钥环。密钥可以：”
  - 重试
  - 保存到本地文件（0600）
  - 取消

选择本地文件后，设置页顶部显示常驻警告条：“密钥以 0600 文件存储，建议使用环境变量或启用密钥环。”

## 6. 校验规则

- `debounce_ms` ∈ [200, 2000]。
- 自动翻译关闭时，延迟值仍保存，但 UI 禁用。
- 启用火山引擎：Access Key、Secret Key 非空。
- 启用腾讯云：SecretId、SecretKey 非空。
- 区域非空；允许自定义。
- 至少启用一个翻译源；全部关闭时保存前提示“将没有可用的翻译源”，允许保存但主窗口显示空状态。
- 字段错误就地显示在对应行下方，不使用弹窗。

## 7. 测试连接（P1，可延后）

- 每个云厂商行提供“测试连接”。
- 使用当前输入框中的密钥（或环境变量），发送 `hello` → 目标语言，超时 5s。
- 成功：显示“连接成功 · 123ms”。
- 失败：显示脱敏错误（如“认证失败”“网络超时”），不回显请求头。
- 测试不保存配置、不写入密钥环。

## 8. 关闭与未保存修改

- 有未保存修改时关闭窗口，弹出确认：“放弃未保存的修改？”
- `Esc` 等同于“取消”；有修改时先确认。
- 保存成功后关闭窗口（或保留？v0.1 选择关闭，减少窗口数量）。
