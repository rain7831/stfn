# 主窗口与交互设计

> 状态：已按 v0.1 实现校准
> 关联：`README.md`、`architecture.md`、`settings.md`

## 1. 设计原则

- 单列、纵向、从上到下：输入 → 各平台结果。
- 键盘优先；鼠标操作不挡路。
- 无多余 chrome；译文优先于装饰。
- 稳定布局：请求过程中不重建行、不跳动。
- 跟随系统主题（libadwaita），浅色 / 深色自适应。

## 2. 窗口尺寸

- niri 规则初始宽度为屏幕 25%；用户可用 `Mod+R` 或拖拽调整。
- 最小内容宽度 320px；默认高度 640px（平铺时高度由 niri 布局决定）。
- 输入区最大高度为窗口的 40%，超出滚动。
- 结果区占据剩余高度，独立滚动。

## 3. 布局

```
┌──────────────────────────────────────────────┐
│  STFN                                    ⚙  │  AdwHeaderBar
├──────────────────────────────────────────────┤
│  ┌────────────────────────────────────────┐  │
│  │ 输入中文或英文，自动翻译…              │  │  GtkText（多行）
│  │                                        │  │
│  └────────────────────────────────────────┘  │
│  EN → 中                            [翻译]   │  方向 badge / 手动翻译
├──────────────────────────────────────────────┤
│  Bing                               ⟳ 复制  │
│  你好                                        │
│  /həˈloʊ/  ▶                                 │
├──────────────────────────────────────────────┤
│  阿里云                              复制   │
│  你好                                        │
├──────────────────────────────────────────────┤
│  …                                           │
└──────────────────────────────────────────────┘
```

### 3.1 顶栏

- `AdwHeaderBar`，标题固定为 `STFN`。
- 右侧齿轮按钮在主窗口内 push 设置页（`Ctrl+,` 同效），不新开浮动窗口。
- 不使用菜单；v0.1 只有设置入口。

### 3.2 输入区

- 控件：`GtkText` + `EntryBuffer`，放在 `GtkScrolledWindow` 中。
- `GtkText` 支持多行；`Enter` 换行，`Ctrl+Enter` 立即翻译。
- 输入文字与结果文字统一使用 22px 左侧起点（内容边距 12 + 文本内边距 10）。
- 输入区与结果区之间有一条 `GtkSeparator` 分割线。
- 自动翻译开启：输入停止 `debounce_ms` 后触发；关闭：只有 `Ctrl+Enter` 或“翻译”按钮触发。
- 自动翻译关闭时，右侧显示“翻译”按钮；开启时按钮隐藏。
- 方向 badge 显示 `EN → 中` / `中 → EN`；空输入时隐藏。
- 占位文本：“输入中文或英文，自动翻译”。
- 打开窗口自动聚焦；`Ctrl+L` 重新聚焦。
- `Esc`：输入非空 → 清空；输入为空 → 关闭窗口。
- 输入法组合（preedit）期间不触发翻译；候选词上屏后才开始计时。

### 3.3 结果行

每个启用平台一行，按配置顺序排列。

| 区域 | 内容 |
| --- | --- |
| 左侧 | accent 圆点 + 平台名称（12px，`heading`，不使用 `dim-label`） |
| 右侧 | 音标（可选）、播放按钮（v1.1，可选）、复制按钮、重试按钮（仅错误时）、加载 spinner |
| 主体 | 译文（16px，可选中，自动换行，左对齐） |
| 错误 | 错误说明（13px，`error` 样式）+ 重试按钮 |

- 加载中：保留上一次译文并降低透明度（0.6），标题行显示 spinner；没有旧结果时显示“翻译中…”。
- 错误：保留上一次成功译文（若有），下方显示错误；不把错误覆盖到译文位置。
- 复制：复制纯译文；成功后图标变为勾 1.2s，再恢复。
- 音标 / 播放：数据存在才渲染，不占位；v1.1 实现。
- 结果行之间用 `GtkSeparator`，不使用卡片堆叠。
- 方向 badge 使用 accent 色，不使用淡灰。

### 3.4 空 / 全局状态

| 状态 | 展示 |
| --- | --- |
| 无启用平台 | 结果区提示“未启用任何翻译源”，用户可点顶栏齿轮进入设置 |
| 空输入 | 结果区清空，仅显示占位提示 |
| 全部平台失败 | 结果区顶部显示全局错误条 + 各平台行错误 |
| 不支持的语言 | 输入区下方提示“v1 仅支持中英互译” |
| 缺少凭据 | 对应行显示“缺少凭据，打开设置”，不发请求 |

## 4. 设置页

设置页在同一窗口内通过 `AdwNavigationView` push，顶部为返回 / 设置 / 保存；主页面与设置页共享窗口宽度。详细字段与密钥语义见 `settings.md`。

## 5. 状态机

```
Empty ──输入──> Debouncing ──计时到──> Loading ──> Success / Partial / Error
  ↑                    │                                  │
  └────清空────────────┴──────────新输入（丢弃旧结果）─────┘
```

- `Debouncing` 期间不显示 spinner，避免闪烁。
- `Loading` 时旧结果保留，spinner 表示进行中。
- 新输入使 `generation` 递增；旧 generation 的结果直接丢弃。
- 自动翻译关闭时跳过 `Debouncing`，由显式操作进入 `Loading`。

## 6. 输入法与焦点

- 使用 `GtkText`，走 Wayland `text-input-v3`；fcitx5 候选框跟随光标。
- 不在 `changed` 回调里做同步网络 / 重计算。
- 组合期间不更新方向 badge；commit 后更新。
- `preedit` 验证：若 fcitx5 在组合期间触发 `changed`，监听 IM context 的 preedit 起止，暂停 debounce。
- 多行输入时候选框应出现在光标附近；这是 v0.1 手工验收项。
- 焦点顺序：输入框 → 翻译 / 设置 → 各结果行按钮。

## 7. 键盘快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+L` | 聚焦输入框 |
| `Ctrl+Enter` | 立即翻译（忽略 debounce） |
| `Esc` | 清空输入；已为空则关闭窗口 |
| `Ctrl+,` | 打开应用内设置页 |
| `Tab` / `Shift+Tab` | 焦点移动 |
| `Ctrl+C` | 有选中文本时复制；否则不处理 |

## 8. 视觉规范

- 使用 libadwaita 系统色；不硬编码颜色。
- 字体：系统默认；译文 16px，平台名 12px，音标 13px。
- 间距：4 / 8 / 12 / 16 四档；输入卡片圆角 8px。
- 分隔线：1px，`GtkSeparator`。
- 动效：只保留 spinner 与复制反馈；不做布局动画。
- 深色 / 浅色 / 高对比度均使用系统主题。

## 9. 响应式

- 宽度 < 360px：平台名可省略号截断；按钮缩小到 28px；方向 badge 可缩写为 `EN→中`。
- 高度不足：输入区最大 40%，结果区滚动；输入区不滚动整页。
- 多显示器 / 缩放：只使用逻辑像素，不假设 DPI。
- 1/4 屏幕宽度（常见 1728px 屏约 432px）下，译文不应出现横向滚动。

## 10. 可访问性

- 每个输入 / 按钮有可读 label 或 tooltip。
- 焦点环可见；不使用纯图标表达状态。
- 复制结果通过图标 + tooltip 反馈，不只靠颜色。
- 屏幕阅读器可读取平台名、译文、错误。
- 全键盘可完成输入、翻译、复制、打开设置。
