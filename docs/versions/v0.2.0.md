# STFN v0.2.0

> 发布日期：2026-11-12
> Git tag：`v0.2.0`
> 设计文档：`docs/tech/`

## 功能概述

- **英文单词级音标与发音**
  - 英译中：输入单个英文单词时，在输入卡片下方显示 US/UK IPA 与播放按钮。
  - 中译英：每个厂商结果卡片在标题和译文之间显示该译文的 IPA 与播放按钮；不同译文各自查询。
  - 音标来自 `dictionaryapi.dev`；只处理单词，句子/短语不显示 IPA，也不显示中文拼音。
  - 音频来源顺序：词典真人音频 → 有道词典发音（US `type=1` / UK `type=2`）→ Edge TTS。
  - 词典命中后预加载可见 accent 的音频；点击若仍在下载会等待同一个单飞请求，不重复下载。
  - 音频只缓存内存：LRU 64 条 + 8 MiB 总字节 + 1h TTL，不写磁盘，退出即清空。
  - 播放改走 PipeWire/PulseAudio cpal 设备，避免直接打开 ALSA 硬件 PCM 导致有流无声。
  - 播放失败保留 ▶ 按钮并提示重试，不隐藏 IPA。

- **句子级朗读**
  - 英译中：输入是英文但不是单个单词时，输入卡片下方显示“朗读原文 ▶”。
  - 中译英：译文是英文但不是单个单词时，结果卡片 header 显示“朗读译文 ▶”。
  - Edge TTS 优先，失败时用有道发音兜底；不预加载、不做句子音频缓存。

- **系统与手动主题**
  - 默认跟随系统 `AdwStyleManager`；高对比度继续由系统主题处理。
  - 新增 `general.color_scheme = "default" | "light" | "dark"`。
  - 设置页“外观”选择颜色方案，保存后立即生效，重启保持。
  - 手动模式在 USER+1 优先级加载并展开/裁剪 libadwaita 内置主题，覆盖 Noctalia 等生成的静态 GTK 调色板；深色/浅色都能正确渲染。

- **niri 选区翻译**
  - 新增 `stfn selection`：新进程读取 primary selection，清洗后填入输入框并立即翻译。
  - 只读 primary selection；读不到就提示，不回退普通剪贴板、不发送 Ctrl+C。
  - 超过 5000 字符直接拒绝；内部换行保留，控制字符移除。
  - 推荐绑定 `Mod+Shift+Y`；窗口 active 后再读取，避免 GDK 尚无选区数据。

- **进程模型与聚焦**
  - 取消 GApplication 单实例：`NON_UNIQUE`，每次 `stfn` / `settings` / `selection` 都是新进程和独立窗口。
  - 移除 `state_slot`、command-line 转发；`run_with_args` 避免 GApplication 把 CLI 参数当文件。
  - 启动、从设置页返回、选区注入后都聚焦输入框，并补一次 idle 聚焦。

- **CLI**
  - 新增 `stfn selection`。
  - `--speak`：英文译文用 Edge TTS 播放；中文目标返回 1；TTS 失败仍保留已输出译文并返回 1。
  - `--json` 的 `phonetic` 对英文单词填充 IPA（US > UK > generic），未命中为 `null`。
  - 词典请求补 User-Agent；403/429/5xx/网络错误重试一次，瞬时失败不再缓存 24h。

- **配置**
  - 新增 `general.color_scheme`；配置格式版本仍为 1，旧配置无需迁移。

## 主要修复与迭代

- 修复音标行因 `GtkWidget::is_visible()` 连带检查父级而永远不显示的问题。
- 补上词典请求 User-Agent，避免 Cloudflare 403 挑战；瞬时失败不再污染缓存。
- 词典真人音频 CDN 返回 502 时，自动回退有道发音，再回退 Edge TTS。
- Edge TTS 偶发 403 时自动换新连接重试一次；失败保留播放按钮供手动重试。
- 修复 cpal 默认 ALSA 设备绕过 PipeWire 导致“播放成功但没有声音”。
- 修复 AdwStyleManager 被 Noctalia 静态 `gtk.css` 覆盖、手动亮/暗切换无效。
- 修复 libadwaita dark 规则位于 media query 内、手动 dark 仍渲染为 light 的问题。
- 选区读取改为等待窗口 active，解决 GDK 读取早期返回空选区。
- 回退 Edge TTS/Youdao 全部失败时的按钮隐藏行为，改为保留按钮并给 tooltip。

## 验证

- `cargo test`：32 个集成测试通过（CLI 12、GUI 意图 3、配置 1、词典/音频 10、选区清洗 6）。
- `cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`：通过。
- `cargo build --release`：通过；`stfn --version` 输出 `0.2.0`。
- 实机验证：
  - 英译中输入单词显示 US/UK IPA，预加载后点击立即播放。
  - 中译英结果卡片显示各自 IPA；非单词结果出现“朗读译文”。
  - 句子级朗读经 Edge TTS 播放，PipeWire 中出现 `PipeWire ALSA [stfn]` 流。
  - `stfn selection` 读取 primary selection 并自动翻译；超过 5000 字符拒绝（`Mod+Shift+Y` 为推荐 niri 绑定）。
  - Noctalia 静态暗色 CSS 下，手动浅色/深色/跟随系统均可正确切换，保存后无需重启。
  - 多进程窗口独立，关闭即退出。

## 已知限制

- `dictionaryapi.dev` 的音频 CDN 当前可能返回 502；有道和 Edge TTS 作为兜底。
- Edge TTS 为非官方接口，存在瞬时限流；句子朗读的长文本在有道兜底失败时可能无法播放。
- 句子级朗读不预加载、不缓存；重复点击会重新合成。
- 手动主题使用 libadwaita 标准调色板，会覆盖 Noctalia 的自定义配色；选“跟随系统”恢复系统主题。
- 音标只支持英文单词；不支持中文拼音或句子级 IPA。
- v0.2.1 不再计划其他功能；TTS 音色/语速设置、`wtype` Ctrl+C 回退取消。
- 本版本未重新做冷启动/PSS 基准，沿用 v0.1 的目标值。
