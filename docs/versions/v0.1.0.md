# STFN v0.1.0

> 发布日期：2026-11-11
> Git tag：`v0.1.0`
> 设计文档：`docs/tech/`

## 功能概述

- **niri 原生体验**：普通平铺窗口；Wayland app-id 固定为 `stfn`；可在 niri 中绑定 `Mod+Shift+T` 唤起。
- **翻译主界面**：`输入` 提示标题 + 多行输入卡片；`翻译结果` 标题 + 按配置顺序排列的厂商卡片。
- **输入体验**：`GtkTextView` 多行输入、文字从左上角开始；`Enter` 换行、`Ctrl+Enter` 立即翻译；preedit 期间不触发。
- **三翻译源**：
  - Bing：默认、免密钥；网页翻译会话流程，支持 `cn.bing.com` 回退。
  - 火山引擎：`TranslateText` + Signature V4；字段 `TextList` / `DetectedSourceLanguage`。
  - 阿里云：`TranslateGeneral` + HMAC-SHA1；固定 `cn-hangzhou`，不暴露区域配置。
- **自动翻译**：默认延迟 700ms，可在 200–2000ms 调节；关闭后显示“翻译”按钮。
- **设置页**：应用内 `AdwNavigationView` 页面；自动翻译、延迟、厂商开关、密钥、区域已移除。
- **密钥管理**：
  - 已保存显示 `******` 与“· 已保存”；不改动保留，清空删除，新值替换。
  - 环境变量 > Secret Service（`keyring`）> `0600` 凭据文件。
  - 密钥环不可用时需明确允许才写本地文件；设置修改未保存时返回/退出会确认。
- **CLI**：`stfn`、`stfn settings`、`stfn hello`、`--json`、`--notify`、`--source`、`--to`、stdin `-`。
- **性能**：冷启动实测约 157–201ms；PSS 约 43MB / RSS 约 112MB。
- **外观**：官方 Bing / 火山 / 阿里 logo；主页面与设置页使用统一的标题、卡片和留白。

## 主要修复与迭代

- Bing 旧 `edge.microsoft.com/translate/auth` 端点失效，改为网页会话 `IG/IID + key/token` 流程。
- 修复火山翻译：请求字段 `TextList`、响应字段 `DetectedSourceLanguage`；真实密钥验证通过。
- 腾讯云替换为阿里云，移除区域配置和旧 `tencent` 配置字段。
- 修复设置页切换时的 `RefCell` 重入崩溃。
- 修复输入文字垂直居中、主内容拉得过长、结果卡片空荡等问题。
- 移除未采用的 STFN 应用图标资产和相关引用。

## 验证

- `cargo test`：11 个集成测试通过（Bing mock、火山 mock、阿里 mock、CLI/JSON/stdin）。
- `cargo fmt --check`、`cargo clippy --all-targets`：通过。
- `cargo build --release`：通过。
- 真实接口：Bing、火山、阿里云均返回翻译结果。
- UI：25% / 50% 宽度实机检查；设置页、密钥已保存状态、未保存确认弹窗均验证。

## 已知限制

- fcitx5 中文输入/preedit 仍需在目标 niri 会话做一次手工验收。
- 浅色主题未单独实测；当前主要验证深色主题。
- 朗读与音标已转入 v0.2 规划（原 v1.1 占位）；`--speak` 在 v0.1.0 返回“朗读不可用”。
- Bing 为非官方网页接口，无 SLA。
- 应用图标暂不提供；厂商 logo 保留。
- 内存按 RSS 统计略高于 100MB 目标；按 PSS 约 43MB。
